# Obsidian 知识库项目指令

本目录是通过 Obsidian CLI 和本地 Git 管理的个人知识库。

1. 用户要求记录、整理、归档、建立主题、更新项目或生成复盘时，先阅读 `90-系统/整理规则.md`。
2. 优先使用 `obsidian` CLI 读取和修改笔记，保持 Obsidian 运行；CLI 不可用时暂停整理并说明原因。
3. 每批整理必须遵守版本快照、整理日志和验证要求，不得省略。
4. 可以自动移动、归档、补属性、补双链和改写正文；不得虚构来源、研究结论或任务完成状态。
5. 不自动永久删除知识内容，不移除迁移备份，不配置远程 Git。
6. 公司研究资料遵守 `40-资源/公司研究报告/99-归档与使用说明.md`，历史市场事实不得回写。
